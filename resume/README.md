## When a new résumé arrives
1. Move the current PDF into `archive/` with its year (and month, if there's more than one that year) in the name, for example `archive/Pradipkumar-Jaliya-Resume-2026-04.pdf`. Never delete an old résumé.
2. Save the new PDF here under the **same name**, `Pradipkumar-Jaliya-Resume.pdf`, so the download links keep working.
3. Update the date and SHA-256 above (`sha256sum Pradipkumar-Jaliya-Resume.pdf`).
4. Update `profile.md` to match the new résumé, then the website pages that show those facts.

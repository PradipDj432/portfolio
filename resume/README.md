## When a new resume arrives
1. Move the current PDF into `archive/` with its year and month in the name, for example `archive/Pradip-Jaliya-Resume-2026-04.pdf`. Never delete an old resume.
2. Save the new PDF here under the **same name**, `Pradip-Jaliya-Resume.pdf`, so the download links keep working.
3. Update the date and SHA-256 above (`sha256sum Pradip-Jaliya-Resume.pdf`).
4. Update `profile.md` to match the new resume, then the website pages that show those facts.

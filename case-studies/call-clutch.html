Case studyCall Clutch

A call tracking platform for sales teams.

A dialer, lead management and call tracking for inbound and outbound calls, designed and built end to end on Amazon Connect, Lambda, React and Node.js.

01Problem

Sales teams needed one place for their calls and leads.

Sales teams make and take a lot of calls. They needed to dial their leads, manage those leads, and track every inbound and outbound call, without switching between separate tools.

02Solution

One platform for dialing, leads and call tracking.

I led the build of Call Clutch and did all of the work myself: the front end, the back end, the call handling and the reports.

  • A dialer and lead management for sales teams, for both inbound and outbound calls.
  • Call forwarding, campaign creation and phone number assignment.
  • Reports and charts built with AWS QuickSight.
  • Designed with scalability and high availability in mind.

03Architecture

Real-time calls on AWS, everything else on Node.js.

  1. Calls: Amazon Connect handles the phone calls, and AWS Lambda reacts to them at run time, so call handling stays fast.
  2. APIs: Node.js REST APIs serve the React front end. They are easy to scale.
  3. Data: a relational database holds the data, replacing the first version's DynamoDB tables.
  4. Reports: AWS QuickSight turns that data into charts.

The first version was serverless: React, Python on Lambda behind API Gateway, and DynamoDB, with Amazon Connect for calls.

04Technologies

What it runs on.

  • Amazon Connect
  • AWS Lambda

  • React

  • DynamoDB

05Challenges

Slow, hard-to-combine data, and keeping calls fast.

  • Data across tables. Getting related data out of different DynamoDB tables was difficult and slow, so I moved the data to a relational database.
  • Moving the APIs. The front end needed APIs that are easy to scale, so I moved them from Lambda and API Gateway to Node.js REST APIs. Amazon Connect and Lambda stay in place for real-time call handling, where fast invocation at run time matters.

06Results

It runs real sales teams every day.

Call Clutch serves 15 customers and more than 80 users, with 450+ calls and about 10,000 call minutes a day.
